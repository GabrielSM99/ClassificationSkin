# Classificação de Imagens de Pele - Trabalho de IA

Este projeto foi desenvolvido como atividade avaliativa da disciplina de **Inteligência Artificial** da faculdade. O objetivo é implementar e treinar um modelo para a classificação de imagens de lesões de pele.

## Sobre o Projeto
O código principal está estruturado no notebook `AlgoPeleY.ipynb`, onde realizamos o carregamento, pré-processamento e o treinamento do modelo de rede neural para a identificação e classificação das imagens de pele.

## Pré-requisitos
Para executar este projeto, você precisará ter instalado:
- Python 3.8+
- Jupyter Notebook
- Bibliotecas descritas no `requirements.txt`
